# tall_tripod v4 を 4 mm・自己支持拘束つきで回した記録（2026-09-05）

`03_optimization/`（10 mm、拘束なし）と同じ study を、`--voxel 4 --iters 120` で `topopt run` したもの。
`design.overhang`（既定 true、spec Phase 11）で **積層方向 +Z に沿って 45° の円錐に支えられた材料しか置けない**
という規則を最適化の中で課している。**印刷するものではない**（検証モデル）。

| | 拘束なし（`v4_4mm_gpu_2026-09-05/`） | 自己支持（この run） |
|---|---|---|
| 反復 / 所要 | 80 / 342 s | 120 / 820 s |
| 接地 | 5 パッド 1,504 mm² | 6 パッド 2,032 mm² |
| 非支持ボクセル（最適化材料） | 460 個 / 7,360 mm² | **0** |
| 平滑 STL の要サポート面積（`topopt overhang`） | 2,079 mm²（4.7 %） | 1,407 mm²（3.0 %、ほぼ頭部下面） |
| 浮き島 | 0 | 0 |
| 最悪ケース SF p99.5（LC3sw） | 90.8 | 167.2 |
| 収束 | 未（振動） | 未（形状変化 0.0020、閾値ちょうど） |
| メッシュ判定 | FAIL（最薄 8 mm = 2 ボクセル） | FAIL（最薄 11.3 mm = 2.8 要素） |

残る 2 件の FAIL はどちらも解像度・反復数の問題で、3 mm・150 反復で潰す（`v4_3mm_selfsupport_2026-09-05/` を参照）。
頭部（preserve）の下面は最適化の対象外なので CAD 側で面取りする。`--out` 出力なので 4 段階構成ではない。
