# Phase 6 比較：材料モデルと造形方向（2026-09-08）

`03_optimization/` の記録（直交異方性 PLA、`build_axis: Z`、10 mm、80 反復）と**同じ study**を、
3 通りに書き換えて `topopt run --iters 80 --no-ccx` で回したもの。**印刷するものではない。**

| フォルダ | 変えたもの | それ以外 |
|---|---|---|
| `iso/` | `--isotropic`（旧 2 定数モデル、E_xy 3000 / E_z 2400） | 同じ |
| `build_x/` | `build_axis: X`、`raster_axis: Y`、**`ground_axis: Z`** | 同じ |
| `build_y/` | `build_axis: Y`、`raster_axis: X`、**`ground_axis: Z`** | 同じ |

`ground_axis` は今回足したノブ（spec §8.3、`topopt/docs/design-space.md`）。これが無いと
`build_axis` を X にした瞬間に「下」も X になり、部品が横倒しで別の面に立つ別問題になる。
study はこのフォルダ直下（`*_study.json`）に置き、出力は各サブフォルダへ——**study を `--out` の
中に置くと run の要約が同名で上書きする**（lessons-learned #79。最初の3回はこれで extract が落ちた）。

## 読み方

- **等方モデルは 2 倍硬く見える。** 同じ体積で最大変位 0.0345 → 0.0162 mm、支配ケースの安全率 76 → 99。
  層間方向を楽観視する旧モデルの性質そのもの（CLAUDE.md の「閉形式のほうが甘い」と同じ向き）。
  形はほぼ同じ（体積 309 → 304 cm³、パッド 6 → 6）で、**材料モデルは形より数字を変える**。
- **造形方向は形を変える。** X 造形は接地パッドが 6 → 3 に減り、Y 造形は 1 つの広い接地面（4,700 mm²）に
  まとまった。異方性最適化は層間引張を避ける向きに材料を置き替えるので、同じ荷重でも別の三脚になる。
  Y 造形の LC3sw（片脚引っ掛け）は安全率 37 と他の 1/3〜1/4——**片脚を持ち上げる荷重が層をはがす向きに
  なった**ケース。
- **サポート体積は Z 造形が最小**（341,000 mm³）。横倒し造形は X で 4 倍、Y で 2 倍。
  立った部品を横に寝かせて印刷する理由は無い、という当たり前の結論が数字で出た。
- 4 変種とも判定は同じ 3 件で FAIL（`max_iterations`・最薄部 2 要素でグリッド律速・自己支持で数ボクセル）。
  いずれも study 側の既知課題（known-issues G1 / G4 / G6）で、変種間の差ではない。
- **これは 10 mm グリッドの比較**。数字は known-issues G10 のとおり CalculiX より 1.4〜1.6 倍硬い側に
  ずれているが、4 変種は同じグリッドなので相互比較は対称（E1 の非対称性は無い）。
