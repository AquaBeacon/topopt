# v7 — 旧頭部の密度場で、新しいカメラマウントを載せた版（2026-09-10、置き換え済み）

これは **v8 が上書きする前の記録**です。中身は「v5 で解いた密度場」＋「v7 で差し替えた
カメラ固定部（子機用 DJI Osmo Action 6 マウント）」の組み合わせ。

## なぜ捨てたのか

**最適化が見ていた取合いが、実際に載せたものと違いすぎました。**

| | 解析が見ていたもの（v5 の密度場） | 実際に載せたもの（v7） |
|---|---|---|
| 取合い | 15 × 15 mm の台座、接合面 18 × 18 mm | 104 × 79.45 mm の底板 |
| 高さ | z = 110..146（36 mm） | z = 112..196.5（84.5 mm） |
| 体積 | 17,064 mm³ | 143,505 mm³ |

つまり **104 × 79 mm の板を 15 mm の首で支える形は、誰も解いていませんでした**。
形としては繋がっていて、寸法も測ってありますが（`check_mount_interface.txt`）、
**構造としての裏付けはありません**。利用者の判断で v8 として解き直しています。

## ここに何が入っているか

`03_optimization/` と `04_print/` から、**もう一度読む価値のあるものだけ**を写してあります
（`.frd` など数百 MB の CalculiX 生データは写していません）。

| ファイル | 中身 |
|---|---|
| `tall_tripod_study.json` | 実行時の study のコピー（v7 の設定そのもの） |
| `tall_tripod_study_density_phys.npy` / `_raw.npy` | **v5 で解いた密度場**。3 mm・84×84×54 |
| `tall_tripod_study_binary.npy` | しきい値 0.40 の 0/1 |
| `tall_tripod_study_extract.json` | finish 0.5 mm の結果一式（取合い寸法つき） |
| `report.md` / `report.json` | 判定 FAIL（収束・メッシュ収束・自己支持） |
| `printcheck.json` / `slice.json` / `PRINT.md` | 造形性・スライス（7h14m / 303.25 g / サポート 45.9 %） |
| `check_mount_interface.txt` | 出荷 STL とソース STL の取合い実測。**全項目一致** |
| `run.log` / `rerun_v6.log` / `rerun_v7.log` | 実行ログ |

## v8 に持ち越した知見

- **取合い寸法の測り方と結果は有効です。** finish 0.5 mm なら、この段は誤差を足しません
  （二面幅 8.12 がソースと一致、爪 6.00 / 2.75 / 3.00、溝 3.25）。v8 の finish 設定は同じ。
- **ナット座の余裕 0.02 mm** は元 CAD 側の問題で、解き直しても変わりません → known-issues G15。
- スライス値は**出荷する形**を測ったものです（2026-09-10 の修正後）→ lessons-learned #98。
